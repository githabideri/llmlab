02 raw jev schema — this is /v1/systemone with a face (or let the prompter write it for you)

Programmatic consumers: POST /v1/systemone with the same json — it speaks the TypeSafe schema at any base url. Bulk: POST /v1/batch {"states": […], "questions": {…}} → per-state answers (cap 25, sequential on CPU). usage.output_tokens is always 0: the model scores options in one pass and never generates text. The gate control in the nameplate treats choice/noul answers below the confidence threshold as undetermined (scores are never gated). Measured caveat: confidence is a real gate for concrete-observable questions ("is a refund explicitly requested?") but not for comparative ones ("does claim A contradict fact B?") — there, treat a confident contradiction as an advisory flag and route the rest to a bigger model. Details in the decision-classifiers methodology.

03 latency vs question count — one prefill, one batched pass

On this 2-core CPU box the cost is ~500-600 ms fixed + ~540 ms per question (each question gets its own 512-token encoder slice, so it scales roughly linearly — the "free parallel pass" picture only appears on a GPU, where the same model does ~35 ms per Laya's numbers). If sub-100 ms matters, the move is to a 12 GB GPU card (Laya's own numbers: ~35 ms there), not bigger prompts.
